## Destino turístico asignado
Salinas, provincia de Santa Elena - Ecuador.

## Descripción del proyecto
Salinas Paradise Travel es un sitio web desarrollado como parte del examen práctico de la asignatura Diseño de Sitios Web. El proyecto presenta información turística sobre Salinas, incluyendo sus principales atractivos, servicios turísticos, información de la agencia y un formulario de contacto.

El objetivo es promocionar este importante destino turístico de la costa ecuatoriana mediante un sitio web moderno, organizado y adaptable a diferentes dispositivos.
